# **<p align="center"> SCORPION-CHESS </p>**

## <p align="center"> A Chess Engine built from screatch, featuring a playable UI :) </p>

_SCORPION-CHESS_ is my first chess game engine. It combines a custom-built chess engine and GUI, allowing users to play against the engine.

This project is part of a self-proposed extension to my ICS4U coursework.  

#### Features

- Playable chess game
- The custom-built _SCORPION-CHESS_ engine, _scorpionEngine_.
- A functional gui
- Minimax algorithm for move selection
- Alpha-beta pruning for optimizing Minimax
- Java language

#### Requirements & Installation Steps

0. A JRE is required.
1. Visit the Releases page
2. Download the executable JAR of the latest release
3. Execute the JAR using the instructions on the release page
4. Enjoy _SCORPION-CHESS_!

#### Dependencies

_SCORPION-CHESS_ would not be possible without chesslib by @bhlangonijr. See THIRD-PARTY-NOTICES.md for more details.
